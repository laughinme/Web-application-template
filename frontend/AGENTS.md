## Frontend rules

- Read `docs/frontend/architecture.md` (repository root) before changing code here.
- Feature-Sliced Design: `_app > _pages > widgets > features > entities > shared`. Import only
  downward, other slices only through their `index.ts`. `npm run check:architecture` (steiger) fails otherwise.
- `app/` is routing only: one-line re-exports of a page or layout from `src/`.
- API types come from `src/shared/api/schema.d.ts`, generated by `make openapi`; never write DTOs by hand.
  Wire format is mapped to UI models in `entities/*/api/mappers.ts`.
- Errors: switch on `error_code` with `problemMessage()` from `@/shared/api`, never on `detail` text.
- Server state lives in TanStack Query with key factories (`userKeys`); no copies in React state.
- UI text is Russian. UI follows `DESIGN.md` at the root when a project has one; check rendered
  screens at 1440 and 390 px before calling UI work done.
- `npm run check` and `npm run test:e2e` must pass.
